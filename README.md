# Meditrack 💊

Meditrack is a simple mobile application built using **Expo (React Native)** as a beginner project. The goal of this app is to help users manage their daily medicines in an easy and organized way.

## 🚀 Features

- ➕ Add medicines with basic details  
- ⏰ Set reminders for timely intake  
- 📋 View a list of all added medicines  
- 🔔 Get alerts to avoid missing doses  

## 🛠️ Tech Stack

- React Native (Expo)
- JavaScript
- Basic State Management (useState)

## 📱 Purpose

This project was built as a first step into React Native development. It focuses on understanding core concepts like component structure, state handling, and user interaction.

## 📌 Future Improvements

- Edit/Delete medicines  
- Push notifications for reminders  
- Better UI/UX  
- Backend integration for data persistence
